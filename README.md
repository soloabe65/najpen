# najpen

NAJPEN GLOBAL INTEGRATED LTD — corporate website for a world-class Nigerian oil & gas services company (drilling, fabrication, construction, well services, installation, manpower).

## Tech Stack

- React 19 + Vite
- Tailwind CSS 4
- Framer Motion
- React Three Fiber / drei / three
- React Router 7
- Oxlint

## Getting Started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start dev server
- `npm run build` — production build
- `npm run preview` — preview production build
- `npm run lint` — run Oxlint
